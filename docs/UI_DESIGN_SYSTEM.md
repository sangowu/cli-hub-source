# CLI Hub UI 设计规范

终端默认背景统一使用 `#101418`；xterm 根节点及旧视口层与内容区保持同色，避免内边距和网格余量呈现纯黑边。保留现有 10px/12px 内边距和字符网格尺寸。

会话缩略内容使用固定 31px 的两行区域。连续输出期间保留上一条内容，连续 2 秒无新终端输出后再整体替换；首次回复期间保留等待提示。活动状态独立更新。静默判据不能准确判断所有 CLI 的回复完成：生成中的长暂停可能提前更新，持续后台输出可能延迟更新。

本规范以当前 Windows 界面为基准：紧凑、清晰的终端工作台。扩展界面时优先复用现有组件样式，避免为单个按钮或设置项另写一套尺寸。实现入口为 `src/App.css`、`src/App.tsx` 和 `src/i18n.ts`。

## 字体与文字层级

界面使用 `--font-interface` 定义的字体栈；终端使用独立的字体设置。普通文字使用 400 字重，强调文字使用 700 字重。

| 用途 | 字号 | 样式入口 |
| --- | --- | --- |
| 主界面标题 | 24px | `.app-brand`，32px 应用图标，CLI 主题文字色 / Hub 青蓝色 |
| 紧凑对话框标题 | 19px | 设置、新建会话、停止及退出确认对话框标题 |
| 对话框眉题 / 顶部说明 | 10px / 11px | 对话框头部样式 |
| 设置名称、分区标题、快捷键名称 | 12px，700 | `.settings-option strong`、`.settings-section-title`、`.shortcut-row > span` |
| 设置说明 | 10px，行高 1.4 | 设置说明样式、`.settings-section-description` |
| 设置选择框、键位输入框 | 13px | `.settings-dialog select`、`.shortcut-key-input` |
| 设置内操作按钮 | 13px，700，行高 1.2 | `.settings-action-button` |
| 对话框底部操作按钮 | 13px，行高 1.2 | 对话框底部按钮样式 |
| 默认终端文字 | 14px | 终端配置 |

## 按钮

顶栏品牌标识复用应用的终端叠层图标，与 CLI Hub 等宽字标保持 10px 间距。整体最小高度 34px，与右侧按钮居中对齐；保持单行，不添加额外眉题或副标题。Hub 强调色在亮色主题使用 `#147a9d`，暗色主题使用 `#6ecce4`，图标为装饰性图片，标题可访问名称保留 CLI Hub。

| 类型 | 尺寸 | 使用规则 |
| --- | --- | --- |
| 设置内操作 | 170 × 34px，圆角 8px，左右内边距 12px | 复用 `.settings-action-button`，例如检查更新、重置快捷键；Done 同尺寸 |
| 检查更新 | 同上，170 × 34px | 同时使用 `.settings-update-button` |
| 对话框底部操作 | 高 30px，左右内边距 12px | 复用对应对话框底部按钮样式 |
| 主操作 / 危险操作 | 遵循所在区域的尺寸 | 使用已有主操作或危险操作样式；最终危险确认同时使用 `.danger-button.shutdown-confirm-button`，保持红底白字 |
| 顶栏设置入口 | 34 × 34px | 图标按钮 |

设置内操作按钮统一提供 hover、2px 的键盘焦点轮廓及 disabled 状态。新增按钮需要声明 `type="button"` 并使用对应组件类，不能仅依赖全局 `button` 默认字体和主题样式。

停止与退出确认窗口共用 `.shutdown-dialog` 的紧凑标题、说明和底部按钮尺寸。底部操作右对齐，取消与确认保持 9px 间距，最终确认不继承普通危险入口的自动左边距。

```tsx
<button type="button" className="settings-action-button" onClick={resetShortcuts}>
  {copy.shortcutReset}
</button>
```

## 设置布局

- `.settings-dialog` 宽度为 `min(600px, 100%)`，外层保留窗口边距。
- `.settings-body` 内边距为 `15px 18px 17px`，内容区限制高度并允许纵向滚动。
- 设置卡片间距为 10px，使用 1px 边框和 11px 圆角。
- 开关设置行最小高度为 60px，内边距为 `10px 12px`。
- 语言、更新、快捷键及后台 CLI 会话卡片内边距为 `11px 12px`。
- 后台 CLI 会话复用 `.settings-section-title` 和 `.settings-section-description`；操作放在 `.settings-section-actions`，与说明间距 10px，右对齐。
- 语言及快捷键行使用 `minmax(0, 1fr) 170px` 两列，列间距 14px；说明可自然换行。
- 选择框和快捷键输入框高 34px，内边距 `7px 10px`，圆角 8px。
- 快捷键重置操作在卡片底部右对齐；智能复制开关复用设置行，并以分隔线区分。
- 在应用最小窗口 720 × 600 下，所有设置应可通过纵向滚动访问，无横向溢出。

## 亮色与暗色

主题由根元素 `data-color-mode` 切换。新组件需要同时定义亮色和暗色状态，并确保组件状态不会被通用按钮规则覆盖。

| 元素 | 亮色 | 暗色 |
| --- | --- | --- |
| 设置卡片背景 / 边框 | `#ffffff` / `#d5dee4` | `#141d24` / `#30414b` |
| 设置名称 | `#263845` | `#d9e4eb` |
| 设置说明 | `#71808b` | `#8497a3` |
| 设置操作背景 / 文字 | `#f4f8fa` / `#29404d` | `#172630` / `#b8d0dc` |
| 设置操作 hover 背景 / 文字 | `#eef8fb` / `#116f92` | `#1a303b` / `#8dd8f1` |

分类选中状态同时通过颜色、底部标记和勾选符号表达，并设置 `aria-pressed`。其他选择控件也应提供清晰的当前状态，避免仅靠微弱色差表达选择。

工作区标签和终端画布使用独立的深色区域设计。工作区按钮保持透明背景，继承外层标签的选中颜色，关闭按钮悬停使用危险操作配色；通用暗色按钮规则不得覆盖这些组件。`.terminal-focus-exit` 在亮暗主题下均保留深色背景，hover 和键盘焦点使用浅色文字与强调边框，避免浅底浅字。

## 交互、文案与验证

- 终端工具栏右侧提示为“双击CLI界面可进入全屏模式”；英文为“Double-click the CLI view to enter fullscreen mode”。对应现有双击终端进入专注视图的行为。

### 会话栏折叠

- 展开宽度为 190–360px，卡片宽度 162px，横向容纳一到两列，包含间距和滚动条；顶部提供 28px 折叠按钮。收起时固定为 52px 图标栏，隐藏拖拽分隔条。
- 会话列表固定预留滚动条空间，水平内边距 8px，为两列在小数缩放/DPI 下保留宽度余量。拖动任一分割条时保持当前终端网格，松开、取消或失焦后再适配尺寸，避免每帧清屏重排；终端实例始终保留。
- 应用顶部只保留 CLI Hub 标题与操作控件，移除 stage/subtitle 介绍文案，为工作区留出高度。
- 终端内边距放在 `.xterm` 上，供 FitAddon 扣除；不要放在终端父容器上，否则行列数过大导致底部/右侧裁切。
- 卡片优先展示最近识别到的 Claude/Codex 回复，过滤输入提示与常见状态栏。未知输出格式回退到过滤后的最近输出，不持久化内容。
- 图标按钮为 36 × 36px，间距 8px，按当前分类顺序排列；内容过多时纵向滚动。
- 每个图标显示 CLI 缩写、会话编号和状态点。选中状态使用强调背景和加粗左边框，并提供 `aria-pressed`；状态也写入可访问名称。
- 悬停说明包含名称、CLI 类型、状态和目录；切换图标不会展开栏。分类、预览和停止/移除操作在展开视图提供。
- 折叠按钮提供中英文名称、`aria-expanded`、控制区域关联和可见键盘焦点；保存期间禁用，保存失败时保持原布局并显示错误。
- 工作区和图标栏使用独立的深色区域配色，通用暗色按钮规则不得覆盖图标栏按钮状态。
- 最小窗口规则不得覆盖收起后的 52px 宽度。展开后恢复本次运行中的宽度及各工作区列表滚动位置。
- 折叠偏好保存到现有 `uiSettings.sessionSidebarCollapsed`，默认展开；终端容器不因折叠重新创建，尺寸变化复用 ResizeObserver。

### 检查要求

- 文案进入现有 i18n 字典，检查中英文显示和长文本换行。
- 输入和操作具有可识别标签；键盘焦点可见，禁用状态可辨认。
- 修改前查找可复用类；同类操作共享字号、字重、高度、圆角和主题状态。
- 修改后检查亮色、暗色、中英文、正常窗口和最小窗口；对照实际渲染及计算样式。
- 前端改动运行 `npm run build` 和现有 `python scripts/verify_stage4_ui.py` 回归检查。
- 会话栏改动增加运行 `python scripts/verify_session_sidebar.py`，检查多会话状态、滚动、切换、偏好恢复和保存失败处理。
- 涉及终端行为时，还需进行真实 Tauri/WebView2 验证；模拟界面检查不替代原生行为验证。
- 新增或调整通用设计规则时同步本文件；修复记录写入 `docs/DECISIONS.md`。
